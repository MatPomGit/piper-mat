# Język dokumentacji

Dokumentacja i materiały użytkowe projektu są prowadzone w języku polskim. Zasady tłumaczenia terminów technicznych opisano w [terminologii projektu](TERMINOLOGIA.md).

Angielskie nazwy pozostają wyłącznie tam, gdzie są częścią interfejsu technicznego, nazwy biblioteki, formatu, pliku, parametru wiersza poleceń lub utrwalonego skrótu metryki.
