# Terminologia projektu

Materiały użytkowe projektu `piper-mat` są prowadzone w języku polskim. Nazwy bibliotek, formatów, plików, parametrów wiersza poleceń oraz utrwalone skróty metryk pozostają w formie wymaganej technicznie.

## Zalecane odpowiedniki

| Termin techniczny | Termin używany w dokumentacji |
| --- | --- |
| dataset | zbiór danych |
| checkpoint | punkt kontrolny |
| sample rate | częstotliwość próbkowania |
| batch size | rozmiar partii |
| seed | ziarno losowania |
| train / validation / test split | podział na zbiory treningowy, walidacyjny i testowy |
| smoke test | test poprawności |
| speaker similarity | podobieństwo głosu |
| speaker embedding | osadzenie mówcy |
| real-time factor | współczynnik czasu rzeczywistego |
| peak RAM | szczytowe użycie pamięci RAM |
| clipping | przesterowanie |
| checksum | suma kontrolna |
| release | wydanie |
| upstream | projekt źródłowy |

Nie tłumaczy się nazw i identyfikatorów takich jak `Piper`, `eSpeak NG`, `ONNX`, `Git LFS`, `PyTorch`, `CUDA`, `WER`, `CER`, `MOS`, `CMOS`, nazw plików ani opcji takich jak `--checkpoint` i `--sample-rate`, ponieważ stanowią element interfejsu technicznego lub standardową nomenklaturę.
